# Runic Command Line 0.6.0-preview.6

Unreleased. These notes collect changes merged after 0.6.0-preview.5.

## An alias for the JSON output selector

- `CommandCatalogBuilder.JsonOutputAlias("--json")` declares a flag that stands
  for `--output json`, so an application that already has a `--json` flag keeps
  its users' command lines. The flag takes no value, is recognized wherever the
  selector is (also before the command, never after `--`), maps to a host's
  transport option such as `--runic-output`, and is listed in help ("Same as
  --output json") and in completions. `GeneratedCommandCatalog.Create(builder =>
  builder.JsonOutputAlias("--json"))` declares it for a generated catalog.
- Giving the flag and the selector together is the new usage error `RCLI1016`
  (`conflicting-output-selector`), which names both spellings. The flag twice is
  `RCLI1007`, and the flag with a value is `RCLI1004`.
- A command option spelled like the flag, or combined catalogs that declare
  different flags, fail catalog validation with the new `RCLI0024`.
- The grammar specification and corpora cover the alias: the fixture catalog
  declares `--json`, with 4 new grammar and 8 new output-classification rows.

## New public API

- `CommandCatalogBuilder.JsonOutputAlias(string)`, `CommandCatalog.JsonOutputAlias`
- `CommandTextKeys.HelpJsonOutputAlias` (`help.json-output-alias`) and
  `CommandTextKeys.DiagnosticConflictingOutputSelector`
  (`diagnostics.conflicting-output-selector`)

## Install

Use .NET 10 and keep `Runic.CommandLine` and the optional
`Runic.CommandLine.Processes`, `Runic.CommandLine.Spectre` and
`Runic.CommandLine.Testing` packages on the same exact version,
`0.6.0-preview.6`.
