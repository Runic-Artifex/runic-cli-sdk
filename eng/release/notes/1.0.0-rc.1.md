# Runic Command Line 1.0.0-rc.1

## Framework text catalog in Runic.CommandLine

- The English and German framework text (the `runic-command-line` catalog)
  moved from `Runic.Translations.CommandLine` into this repository, next to
  `CommandTextKeys`. The `Runic.CommandLine` package carries it as data under
  `translations/` (`runic.json`, `en.rmf2`, `de.rmf2`) with
  `translations/text-keys.json`, which lists every key with its argument names
  and catalog message name. Nothing there flows into a consuming project, and
  Runic.CommandLine still does not reference Runic Translations.
- The catalog covers every key, including `hints.usage` (German: `Weitere
  Informationen erhalten Sie mit "{command}".`), and its English is the
  English that 0.10 and 0.11 write for usage errors.
- `Runic.Translations.CommandLine` follows each Command Line minor in lockstep;
  the Runic.CommandLine README has the version table. German text for this
  release needs `Runic.Translations.CommandLine` 0.10.0.

What to do: nothing in code. An application that overrides framework text in
`translations/overrides/runic-command-line/` keeps working; the German wording
of the usage errors changed with the English (for example `Die Option '--x'
ist unbekannt.`), so tests that compare German usage errors need the new text.
